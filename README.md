# Arena de Serpientes

Juego de acción y supervivencia por hordas con progresión, mejoras permanentes, guardado local y controles para escritorio y móvil.

## Jugar

Abre `index.html` en un navegador para jugar. Para instalarlo como aplicación y habilitar el modo sin conexión, publica el repositorio con GitHub Pages usando HTTPS; después abre el sitio y selecciona **Instalar app** en el navegador.

## Controles

- Escritorio: mueve el ratón para dirigir a la serpiente; usa los botones o sus teclas indicadas para las habilidades.
- Móvil: usa el joystick táctil y los botones de habilidades.
- Las sesiones y mejoras se guardan localmente en el navegador y dispositivo.

## Archivos

- `index.html`: juego principal.
- `Arena de Serpientes.html`: copia con el nombre original.
- `manifest.webmanifest`: metadatos para instalación PWA.
- `service-worker.js`: caché para juego sin conexión.
- `icon.svg`: icono del juego.

Las partidas se almacenan en el navegador del jugador; no se sincronizan entre dispositivos.
